## Obsidian

Open the `docs` folder as an Obsidian vault and sort files by name (A to Z). Enable the community Kanban plugin to view `Todo.md` as a board. The notes use Obsidian wiki links; the links above also work in repository Markdown viewers.

Documentation and the board live alongside the code so they can be versioned together. Personal Obsidian configuration and cache files are ignored by Git.
